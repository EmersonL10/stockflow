# StockFlow

Sistema Web para la Gestión Operativa y Administrativa de Honoria Express S.A.C.

## Objetivo

Desarrollar una solución web basada en Java para centralizar, organizar y controlar los principales procesos operativos y administrativos de la empresa.

## Tecnologías principales

- Java 21
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Bootstrap
- Maven
- Git
- GitHub
